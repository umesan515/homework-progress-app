====================================
■ プロジェクト概要
====================================

本プロジェクトは、高校等での課題提出・進捗管理を目的とした
Webアプリケーションである。

主な目的
・教師が課題を配布
・生徒が課題を提出
・提出状況の確認
・問題ごとの理解度分析
・クラス単位での進捗把握

将来的には学校外公開も視野に入れた設計。

----------
技術構成
----------

Frontend: Next.js (TypeScript)
Backend: Node.js (Express)
DB: PostgreSQL
サーバー環境: Ubuntu (自作サーバー)
プロセス管理: PM2
リポジトリ: https://github.com/umesan515/homework-progress-app

====================================
■ 重要な開発ルール（必ず守る）
====================================

① 修正コードの出力形式
- ChatGPTが出力する修正コードは必ず「編集の必要なコードファイルを丸ごと置き換える形」で出力する
- 出力形式はZIPファイル

② 不要な変更は禁止
- 修正対象以外のコード変更は禁止
- 不要なリファクタや構造変更は禁止

③ UI変更は禁止
- ユーザーから明示的な指示がない限りデザイン変更は禁止
- ボタンや枠に設定済みのグラデーションは変更厳禁
- ヘッダ上部の緑色部分は現在の単調な見た目を維持する
- 見出しとなる大きな文字は灰色背景の枠（bg-gray-50）の外に配置する
- デザインまわりは指示のない限り変更厳禁

④ システム挙動変更
- ユーザー要件に基づく変更のみ実施する
- 勝手なAPI変更やデータ構造変更は禁止

⑤ Git運用
- git add .
- git commit -m "message"
- git push

⑥ サーバー反映
- cd frontend
- rm -rf .next
- npm run build
- cd ..
- pm2 restart homework-app --update-env
- pm2 restart homework-api

⑦ 開発継続ルール
- ユーザーが了承した最新版コードを正本として扱う
- 過去版に戻さず、その最新版を基準に継続開発する
