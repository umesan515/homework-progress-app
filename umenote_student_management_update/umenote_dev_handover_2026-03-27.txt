UMENOTE 開発引継ぎ文書（2026-03-27更新）

■ 開発方針（最重要）
本プロジェクトでは以下の手順を標準開発フローとする。

1. ChatGPTが修正コードをZIPで出力
2. ZIPを開発PC → サーバーPCへ転送
3. サーバーPC上の ~/homework-progress-app に配置
4. unzip -o で上書き展開
5. frontend の場合は build 実行
6. pm2 restart で反映
7. 動作確認
8. Git add → commit → push

この順序を必ず守る。

------------------------------------------------------------------------

■ 標準コード反映手順

cd ~/homework-progress-app
unzip -o 修正ZIP名.zip

cd frontend
rm -rf .next
npm run build

cd ..
pm2 restart homework-app --update-env
pm2 restart homework-api
pm2 list

■ デザイン・UIルール（厳守）

・ZIP置き換え方式で修正
・不要なファイル変更禁止
・既存UIデザイン維持
・見出しは枠外表示（UI統一ルール）
・教師ホームは生徒ホームと統一デザイン
・headerは単色緑基調を維持
・ボタンや各種枠に設定済みのグラデーションは、明示指示がない限り変更厳禁
・ヘッダの緑色部分は現在の単調な見た目を維持し、勝手に変更しない
・デザインまわりは指示のない限り変更厳禁
・ユーザーが了承した最新版コードを正本として継続し、過去版へ戻さない
